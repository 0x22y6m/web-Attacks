SQL injection UNION Attacks:

When an application is vulnerable to SQl injection , and the results of the query are returned within the application's
responses, we can use the UNION keyword to retrieve data from other tables within the database.
This is commonly known as SQL injection UNION attack.

For a union query to work , two key requirements must be met:
->The individual quries must return the same number of colums.
->The data typees in each column must be compatible between the individual queries.

To met the SQL injection UNION Attack , This conditions need to find out
->How many colums are being retuned from the original query
->which colums returned from the original query are of a suitable data type to hold the results from the 
  injected queries.

** Determining the number of colums required **
When we perfom a SQL injection UNION attack, there are two effective methos to determine how many colums are
being returned from the original query.
-- Method ONE --
  incrementing the specific column index until an error occurs (ORDER By)
  EX: 'ORDER BY 1--
      'ORDER BY 2--
      'ORDER BY 3-- 
    Error -> if we exceeds the number of rows 

-- Method TWO --
   The second method involves submitting a series of UNION SELECT paylods specifying a different number of null values
   EX :' UNION SELECT NULL --
       ' UNION SELECT NULL,NULL --
       ' UNION SELECT NULL,NULL,NULL --
    Error -> if it's doesn't match to no of rows
